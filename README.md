# PG-terminal

An original, TradingQnA-inspired web frame for a private market terminal.

Open `dist/index.html` directly, or serve `dist/` with any static web server.
This first version contains presentation and navigation only. Kite authentication
and EOD updates are not connected to external services.

All pages must load `dist/styles.css` after their page-specific styles. It is the
shared typography contract for the 14px body, 16–18px headings, and 13px
secondary text.
